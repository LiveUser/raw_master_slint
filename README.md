# Raw Master
A RAW image to JPEG XL converter capable of applying LUTs to the output images.
## Note
- Entirely built on Rust
## Features
- Convert RAW images to JPEG XL
- Apply LUTs during the conversion

## Download
[https://snapcraft.io/raw-master](https://snapcraft.io/raw-master)

## Running
~~~
cargo run
~~~
## Building
~~~
cargo packager --release
~~~
